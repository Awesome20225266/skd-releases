# SKD releases

Windows installers and updates for SKD.

[Download the latest installer](https://github.com/Awesome20225266/skd-releases/releases/latest).

Existing 1.1.x users must run the 1.2.0 installer once to enable future updates. After that, SKD checks for published releases at startup and every six hours. Open SKD Settings to check manually, download an update, and restart to install it. Your local settings and data remain in their existing folders.

To use Claude or ChatGPT website chat, open your own signed-in Chrome tab, enable Chrome's Remote Debugging, then use Apps → Preferences → Chat connection inside SKD. Connect existing Chrome and accept Chrome's Allow prompt. Each user connects their own account. Website chat is experimental and supports text replies; agent tasks use the configured engine.

Future app changes become available to installed copies when a new version is built and published here with its installer, blockmap, and latest.yml. Editing source files alone does not publish an update.
